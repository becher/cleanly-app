# ASO / SEO — Cleanly App

## ASO Google Play Store

### Éléments à optimiser
| Élément | Limite | Priorité |
|---------|--------|----------|
| Titre | 30 car. | 🔴 Critique |
| Description courte | 80 car. | 🔴 Critique |
| Description longue | 4000 car. | 🟡 Important |
| Screenshots | 2-8 par device | 🔴 Critique |
| Icône | 512×512 PNG | 🔴 Critique |
| Feature graphic | 1024×500 | 🟡 Important |

### Mots-clés cibles (recherche users)
```
Principaux :
- "delete discord messages"
- "delete tweets bulk"
- "clean social media"
- "delete instagram posts"
- "social media cleaner"

Longue traîne :
- "delete all discord messages fast"
- "bulk delete twitter tweets"
- "clean up social media history"
- "remove old posts automatically"
```

### Template titre optimisé
```
Cleanly – Delete Social Posts
```

### Template description courte (80 car.)
```
Bulk delete Discord, X, Instagram & Reddit. Fast, safe, background service.
```

### Template description longue (extrait)
```
🧹 CLEANLY — The professional social media cleaner

Delete your old posts from Discord, X (Twitter), Instagram, Reddit, Teams,
Bluesky and more — safely and automatically.

✅ WHY CLEANLY?

📱 SUPPORTED NETWORKS

Microsoft Teams • Bluesky • Mastodon • Threads
```

## SEO Landing Page (web)

### Structure recommandée
```
cleanly.app/
├── /                    ← Hero + CTA Download
├── /features            ← Fonctionnalités détaillées
├── /pricing             ← Freemium vs Pro
├── /networks            ← Réseaux supportés
├── /privacy             ← Politique de confidentialité
└── /blog/               ← Articles SEO (comment supprimer...)
```

### Articles de blog à fort trafic
```
"How to delete all Discord messages at once" (22K/mois)
"Bulk delete tweets 2024" (18K/mois)
"Delete Instagram posts in bulk" (12K/mois)
"How to clean up your social media history" (8K/mois)
"Delete Reddit post history" (6K/mois)
"Microsoft Teams delete messages bulk" (3K/mois)
```
